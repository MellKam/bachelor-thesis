## Language caveats

True of every probe of the language, so not repeated in each cell and not counted against any one feature.

- **TinyGo**: The host must call the exported `_initialize` before any other export (the WASI reactor convention); Go's `init()` and the runtime start there. True of every probe, so it is not a cost on any one feature.
- **Kotlin**: The host must run `_start` (the WASI command convention) before any other export; true of every module that built. Feature 17 (`externref`) is built for the `wasm-js` target, every other probe for `wasm-wasi`.

### Kotlin

- **01 Imports and exports**: Annotation, needs an experimental API, @WasmImport / @WasmExport, experimental interop opt-in. Rests on `wasi` (pass).

- **03 Table and indirect call**: Absent (confirmed), function values are GC closures, no table. Rests on `function-values` (fail). The module has no table; 577 `call_ref` sites call function values instead. `WasmTable` is only ever constructed by the binary decoder (parsing a foreign module), never by Kotlin's own codegen path.

- **06 Data segments**: Absent (confirmed), Pointer API over a zero-page memory. - **07 Custom sections**: Absent (confirmed). No probe; what was checked is in [`probes/07-custom-sections/kotlin/ABSENT.md`](../probes/07-custom-sections/kotlin/ABSENT.md).
